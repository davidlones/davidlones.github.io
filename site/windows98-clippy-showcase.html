One system.
Four layers.

Clippy is neither a screenshot nor a web recreation. The Windows 98 guest runs the real Microsoft Agent character and native applications, while the Linux host handles modern networking, push control, and desktop composition.

Sol Chat 98Native Win32 conversation UI with persisted history, context inspection, system diagnostics, menus, status text, and bridge transport.
Sol ClippyIndependent Microsoft Agent controller with direct dialog chat, click reactions, status balloons, paging, and all installed animation states.
Host BridgeAuthenticated HTTP transport for modern TLS, server-side balloon pushes, diagnostics function calls, and full-chat launch control.
Seamless XFCEA shaped, click-through-aware X11 overlay keys out the guest desktop while retaining guest windows, taskbar, Office toolbar, and Clippy.

Two desktops.
One surface.

The guest remains a maintainable Windows 98 installation, but its useful surfaces can be composed alongside ordinary host windows. Clippy stays visible when Sol Chat is minimized or sent to the tray.

Period correct.
Not period limited.

The deliberately boring compatibility choices are the feature: ANSI Win32, WinINet, Microsoft Agent 2.0, file IPC, and a host bridge keep the guest authentic without asking 1998 TLS to survive 2026.

01

Independent Clippy

Chat directly through Agent input, react to mouse clicks, animate, speak in paged balloons, or accept commands from the full chat window.

02

Server push

Host endpoints can show, hide, move, animate, speak, set balloon content, clear only balloon text, and launch full Sol Chat.

03

Useful context

Optional function calls expose the guest process tree, memory, display, network state, computer identity, and other diagnostics to the model.

04

Visible status

Connecting, gathering context, waiting on the bridge, and thinking are shown in Clippy’s balloon before answer text replaces the status.

05

Host controls

An XFCE status indicator provides every animation, balloon and VM controls, plus an LLM-driven idle puppeteer using thermal data, live diagnostics, and a bounded host process tree.

06

Recoverable install

Separate host and guest installers, uninstallers, backup-on-replace behavior, a CD image, source, documentation, and SHA-256 manifests.
