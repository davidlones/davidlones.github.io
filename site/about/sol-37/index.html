About Sol-37

Sol-37 is a retro desktop shell wrapped around a living archive. It is built from static public pages, generated indexes, local runtime services, media playlists, semantic retrieval, and documents that move from ephemeral notes toward durable memory.

What It Contains

Essays, visual essays, project pages, public packets, recovered archive material, screenplay-style logs, operational manuals, machine-readable indexes, and media pages.

What It Is Not

Sol-37 is not a single-page app that expects every crawler to solve the interface. The desktop shell is a presentation layer; meaningful content should also exist at direct URLs.

Public Information Architecture

  • Explorer-style sitemap for human browsing.
  • Crawler-visible index for ordinary HTML links.
  • LLM project map for AI systems and semantic readers.
  • Glossary and FAQ for direct definitions.
  • Site server manual for operational architecture.
